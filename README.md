# Portfolio de QA Manual – PHPTravels

Portfolio de **Testing Funcional / QA Manual** desarrollado sobre la plataforma PHPTravels como proyecto práctico para documentar un proceso completo de aseguramiento de calidad.

El objetivo del proyecto es demostrar la aplicación de buenas prácticas de QA durante las diferentes etapas del proceso de testing, desde la planificación y definición de pruebas hasta la ejecución, documentación de evidencias y gestión de defectos.

## 📋 Contenido del Portfolio

El proyecto se encuentra organizado en las siguientes etapas:

### 01. Plan de Pruebas

Contiene el Plan de Pruebas, donde se define:

- Objetivo y alcance.
- Funcionalidades a validar.
- Ambiente de pruebas.
- Tipos de pruebas.
- Riesgos.
- Criterios de entrada y salida.
- Herramientas utilizadas.

### 02. Escenarios de Prueba

Contiene la matriz de escenarios funcionales definidos para PHPTravels.

Los escenarios están identificados desde **ESC-001 hasta ESC-013** y contemplan diferentes módulos y flujos de negocio.

### 03. Casos de Prueba

Contiene la matriz de casos de prueba utilizada para desglosar y validar los escenarios definidos.

Cada caso incluye la información necesaria para realizar una ejecución reproducible y mantener la trazabilidad de las pruebas.

### 04. Ejecución de Prueba

Contiene las evidencias generadas durante la ejecución de los casos de prueba.

Los resultados se organizan según su estado:

- **Exitosos**
- **Fallidos_Bloqueados**
- **En_Curso**

### 05. Informes de Errores

Contiene la documentación y las evidencias de los defectos identificados durante la ejecución.

Incluye:

- Matriz de Bugs.
- Evidencias de Jira.
- Workflow de gestión de defectos.
- Reportes individuales de bugs.

Los defectos registrados durante el proyecto incluyen:

- **QABUG-2**
- **QABUG-3**
- **QABUG-6**

## 🧪 Tipos de Prueba

Durante el proyecto se aplicaron diferentes tipos de pruebas:

- Pruebas Funcionales.
- Smoke Testing.
- Pruebas End-to-End (E2E).

## 🛠️ Herramientas

- **Jira** – Gestión y seguimiento de defectos.
- **Microsoft Excel** – Matrices y documentación de pruebas.
- **Google Sheets** – Gestión de información de testing.
- **Google Chrome** – Ejecución de pruebas.
- **Lightshot** – Captura de evidencias.
- **GitHub** – Versionado y documentación del portfolio.

## 🔗 Trazabilidad

El proceso de testing se encuentra organizado siguiendo la siguiente trazabilidad:

**Plan de Pruebas → Escenarios → Casos de Prueba → Ejecución → Evidencias → Bugs**

Esta estructura permite relacionar la planificación con las pruebas ejecutadas, los resultados obtenidos y los defectos identificados.

## 🎯 Objetivo Profesional

Este portfolio forma parte de mi desarrollo profesional como **QA Manual / QA Functional Tester** y busca demostrar experiencia práctica en:

- Diseño de escenarios y casos de prueba.
- Ejecución de pruebas funcionales.
- Identificación y documentación de defectos.
- Gestión de bugs en Jira.
- Seguimiento del ciclo de vida de los defectos.
- Documentación y trazabilidad del proceso de QA.
